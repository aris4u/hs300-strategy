# HS300 公式研究

Python版本对Level-2资金行为采用日度大单净额近似映射，与通达信Level-2存在一定区别  。对照表：[docs/l2_mapping.md](docs/l2_mapping.md)。

目标：**无未来函数、T+1 开盘成交、事件研究与完整策略分开、Train 冻结 / Test 不调参**。不优化回测收益。

## 执行口径（研究与生产统一）

- T 日收盘生成信号（可用当日收盘价、成交量、日度大单净额）。
- T+1 日开盘买入 / 调仓。
- **禁止**用 T 日收盘价作为成交价。
- 账本：`signal_date`, `entry_date`, `entry_price`, `exit_date`, `exit_price`。
- 实现：`hs300_strategy/execution.py`；`backtest.py` / `enhance.py` / `screen.py` / UI 均走此口径。
- UI 盘中刷新（`live_refresh`）只给当前查看的股票打上通达信未完成日K并重算信号，**不是**已确认收盘信号，不能当成交依据。

## 图上的交易信号

选股建议页的 K 线只画这些点。图例以这张表为准。

| 信号 | 形状 | 作用 |
|---|---|---|
| 机会点 | 紫色圆点 | 只提示有资金介入，**不买入** |
| 建仓点 | 绿色向上箭头 | **唯一买入**。T 日收盘出信号，T+1 开盘买 |
| 减仓点 | 红色向下箭头 | 减仓。减仓到原来50%-70%左右的仓位 |
| 风险点 | 蓝色菱形 | 只提示，**不自动减仓/清仓** |
| 清仓点 | 深红色叉 | **清仓** |

底色：浅绿 = 满仓；浅橙 = 已经减过仓。

## 指数增强：方案一与方案二

核心仓 70% 跟踪沪深300，增强仓 30%。没有增强信号时，100% 放指数。成交都是 **T 日收盘出信号，T+1 开盘成交**。成分用当前沪深300名单，有幸存者偏差；不能写成选股 alpha。回测窗口 2024-09-02～2026-08-19。

### 设计思路

**方案一 · 环境评分 Top5**  
公式对 300 只都算启动，增强仓每天只等权拿当日个股环境评分最高的 5 只，做弹性。不止盈。逃顶或个股下跌环境离场；波段减到 70%，趋势减到 85%。不追求 2024、2025 每一段都超过指数，全样本超额主要来自 2026。

**方案二 · 启动拿到逃顶 + 风格**  
要解决的是：方案一全样本能赢，但 2024–2025 跑不赢指数。买入仍是建仓点（启动）；不截成 5 只，启动过、还没逃顶的都留在增强仓，大约 230 只。离场只认逃顶，不用波段/趋势减仓。增强仓内部按大盘环境加权：下跌多配银行/公用/煤炭石油/白酒等老登；上涨或近 20 日跌过后的震荡（左拐右）多配电子/软件/电新等科技。风格倍率预先固定，不是事后搜参。

两套都一样：指数近 5 日涨超 4% 时，增强仓临时降到 40%。

| 项目 | 沪深300 | 方案一 | 方案二 |
|---|---|---|---|
| 目标 | 对照基准 | 少量强势股做弹性 | 2024、2025、2026 三段累计都超过指数 |
| 仓位 | 100% 跟踪指数 | 核心 70% + 增强 30% | 同样是 70% / 30% |
| 买什么 | 全部成分，市值加权 | 启动股里按环境评分取 Top5，等权 | 建仓点启动后全部拿到逃顶，约 230 只，再按风格加权 |
| 风格 | 无 | 无行业切换 | 下跌偏老登，上涨或左拐右偏科技 |
| 卖出 | 不主动卖 | 逃顶或下跌环境清仓；波段/趋势减仓 | 只认逃顶，不减仓、不止盈 |
| 持股 | 300 只 | 约 5 只 | 约 230 只 |
| 跟踪 | 跟踪误差 0 | 误差较大，2026 弹性大 | 跟踪更紧 |
| 适合看什么 | 有没有超过基准 | 弹性和 2026 | 三段是否都超过指数 |

### 结果比对

累计收益差 = 组合区间收益 − 同期沪深300。方案二三段累计都超过指数，回撤略小于指数；还没做到每个月都赢。方案一全样本能赢，但 2024–2025 落后。

| 2024-09～2025-12 | +41.80% | +36.10% | +45.57% | −5.70% | +3.76% |
| 2024-09～2024-12 | +20.52% | +19.12% | +21.30% | −1.40% | +0.78% |
| 2025 全年 | +21.19% | +17.75% | +23.63% | −3.44% | +2.44% |

## 两个研究对象

- **A. Event Study**（`event_backtest`）：启动 → T+1 开盘 → 固定持有 N 日。N=5/10/15/20/30/40/60。其中 N=20 为**标准事件窗口**，不是因为结果最好才选。这不是完整策略。
- **B. Full Strategy**（`strategy_backtest`）：完整状态机动态持仓 → 净值、换手、回撤、gross/net。

三类基准：沪深300、全部成分股等权、未入选成分股等权。当前为**非 point-in-time 成分名单**，存在**幸存者偏差**，不得称为无偏基准。

## 下一步与未做的事

这是当前证据还盖不住的地方，不是「做成了就会赚钱」的路线图。公式参数冻结在 `hs300_strategy/config.py`；要改规则只能在 Train 讨论，Test 上看到超额再调参，不算。

**数据与基准**
- 成分改成 point-in-time：现在回测用的是当前沪深300名单，有幸存者偏差。没有历史权重日名单，就不能叫无偏基准。
- 指数口径：核心仓跟踪的是价格指数，不计分红。不要和全收益沪深300混比。
- Level-2：Python 仍是日度大单净额近似，不是通达信盘中逐笔。对不上之前，不能写成「复刻 L2」。
- 交易日历：收盘后自动补 K 按工作日估最后一根；长假可能空转或晚一天，可以接交易所日历。

**研究**
- 相对未入选成分股仍不显著，相对沪深300的超额还分不清是选股还是风格。下一步是行业/市值中性对照，不是再搜一套参数。
- 方案二：2024、2025、2026 三段累计超过指数，但单月仍会输。若要收窄持股或改离场，先写假设、只在 Train 试，并保留现在的方案一/方案二对照。
- Walk-forward 各年符号不稳定。加窗口或切样本前，先固定现在这张分段表，避免只报赢的一段。
- 事后 MFE / 质量评级继续禁止进实时筛选和当日动作。

**产品与工程**
- 选股建议仍是原通达信公式的本意；指数增强是后加的对照，不是已经验证的增强产品。
- 日K 已按「缺了已收盘日再拉」。盘中通达信预览继续不能当成交。
- GitHub 克隆需要本机 Python，仓库里不带 runtime。
- 五档行情依赖本机通达信；没有也能看日K和建议。

**明确不做**
- 不把 Test 上的结果拿去调参。
- 不把评级当买入过滤。
- 不把方案二三段累计超过指数，说成每月都赢，或说成选股 alpha。

## 从 GitHub 运行（Windows）

克隆下来**不能**像桌面 zip 那样只解压双击就稳。需要本机已装 Python 3.13。

```text
git clone <仓库地址>
cd <仓库目录>
python -m pip install -r requirements.txt
copy .env.example .env
python app.py
```

或双击 `HS300.cmd`（会找本机已安装的 Python）。

- 第一次启动会按收盘日自动拉沪深300成分股日K（BaoStock，无需密钥），并重画建议图，可能要十几分钟。
- 资金流 / L2 近似需要在 `.env` 里自己填 `TUSHARE_TOKEN`。
- 建议安装通达信。盘中通达信五档只在本机已安装通达信时可用，没有也能看日K和建议。
- 规则提示，不是投资建议。

```text
python run_research.py          # 研究结论与表1–8
python run_screen.py            # 实时筛选（无质量过滤）
python run_enhance.py           # 指数增强（T+1开盘）

python app.py                   # UI（选股建议页对当前股票约每 20 秒拉通达信行情，重画K线并重算信号；盘中为未收盘预览）
```
